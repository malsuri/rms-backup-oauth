RMS Backup privacy policy

RMS Backup is a private tool with a single user, its owner. It is used only to upload encrypted backup archives to the owner's own Google Drive.

Access it requests

It requests one Google permission, drive.file. That permission lets it see and change only the files that it created itself.

It cannot read, list or change any other file in the Google Drive.

What it does with that access

  • It creates, lists and deletes its own backup files in one folder.
  • It does not collect, sell or share any data with anyone.
  • It does not use Google user data for advertising or for any purpose other than this backup.
  • Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can withdraw the access at any time under Google Account, Linked apps.
